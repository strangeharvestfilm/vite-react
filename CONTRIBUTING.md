# Contributing

Thanks for taking a look at this project.

## Local Setup

```shell
npm install
npm run dev
```

Before opening a pull request, run:

```shell
npm run lint
npm run build
```

## Pull Requests

- Keep each pull request focused on one idea.
- Include a short summary of what changed and why.
- Add screenshots or screen recordings for visible UI changes.
- Call out unfinished edges clearly instead of hiding them.

## Style

Favor readable components, plain names, and small files. This repo should feel like a clean workbench: practical, a little atmospheric, and easy to return to.
