# Security

## Reporting

If you find a security issue, please do not open a public issue with exploit details.

Contact the maintainer privately through the GitHub profile associated with this repository, and include:

- A short description of the issue
- Steps to reproduce it
- Any affected files, routes, or dependencies
- Suggested mitigation, if you have one

## Supported Versions

This repository is a small active lab project. Security fixes target the default branch unless a release branch is added later.
